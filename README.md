# 🌐 Chromium-Powered Advanced Python Web Browser

An advanced, feature-rich web browser built using **Python** and **PyQt6 (Chromium Engine)**. This browser goes beyond standard surfing by integrating built-in privacy, productivity, and utility tools directly into the user interface.

---

## 🚀 Key Features

* 🛠️ **Chromium Core:** Powered by QtWebEngine for modern, secure, and blazing-fast web rendering.  
* 📸 **Smart Screenshot:** Capture full-screen or selected web page areas with a single click.
* 🎥 **Screen Recorder:** Record your browsing sessions with dynamic screen-capturing capabilities.
* 🕵️‍♂️ **History Toggle (On/Off):** Incognito-style privacy control to turn browsing history on or off instantly.
* 🔖 **Bookmark Manager:** Save, organize, and quickly access your favorite web links.

---

## 🛠️ Tech Stack & Prerequisites

* **Language:** Python 3.10+
* **Core Engine:** PyQt6 & PyQt6-WebEngine (Chromium Wrapper)
* **Utilities:** OpenCV & PyAutoGUI (for screen capture/recording)

---

## 📥 Installation & Setup

Follow these simple steps to run the browser locally on your machine:

### Step 1: Clone the Repository
```bash
git clone https://github.com
cd krishnashauryayadav-svg/NEON_WEBBROUSER
```

### Step 2: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 3: Run the Application
```bash
python alpha.py
```
*(Note: Replace `alpha.py` with your primary python file name if different, e.g., `app.py`).*
